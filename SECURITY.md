# 🛡️ Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Security and privacy are taken seriously in **Udyog Mitra**. If you discover a vulnerability or security flaw:

1. **Do NOT publicly disclose the issue** via public GitHub issues or forums.
2. Send an email to the project maintainers with reproduction steps and a description of the potential impact.
3. The maintainers will acknowledge receipt within 48 hours and work with you on a resolution.
